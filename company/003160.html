디아이 공부 - 메모리 검사장비 구조부터 수주·멀티플·결론까지

2026. 11. 7. · 개인 공부 기록용이며, 매수/매도 추천 아닙니다.

디아이가 11/2에 사상 최대 3분기 실적(영업이익 593억, +493%)을 냈는데, 주가는 10/29 4.35만 → 11/6 2.48만 원(-43%). 실적이 좋은데 왜 빠지는지, 지금은 싼 건지 정리해 봄.

메모리 반도체 "검사"가 뭔지 모르는 사람 기준으로 쉽게 적어봄.

PART 0 · 결론 먼저

■ 한 줄 요약

- 메모리 칩은 만들고 나서 뜨겁게·전압 세게 걸어서 불량을 미리 걸러내는 검사(번인)를 거쳐야 팔 수 있음

- 디아이는 그 검사장비(번인 테스터·번인 보드)를 만들고, 자회사 디지털프론티어(지분 65%)는 HBM 웨이퍼 테스터를 만듦. 고객은 삼성전자·SK하이닉스 두 곳

- 실적은 진짜: 26년 1~3분기 매출 4,921억(+45%), 영업이익 1,178억(+266%). 3분기 영업이익률 27%

- 근데 실적 발표(11/2) 후 4거래일 동안 4.10만 → 2.48만(-40%). 11/3 -12.7%, 11/5 -17.6%, 11/6 -13.6%. 이유는 ① 4분기 물량을 3분기에 당겨 납품해서 4분기는 확 줄어듦(예상 영업이익 175억) ② 반도체·코스피 동반 급락

- 결론 먼저: 27년 예상 PER 7.7배로 싸짐. 다만 "27년 수주가 실제로 나오느냐"가 전부. 4분기 실적 공백은 이미 알려진 것이고, 1Q27 신규 수주 공시가 확인 포인트. 2만 원 근처면 확인 전이라도 1차

요약결론부터. "이익은 진짜, 주가는 '4분기 공백 + 내년 수주 의심'에 빠졌다. 내년 수주 공시 하나 확인하고 나눠서 산다." 이걸 산업 → 회사 → 경쟁사 → 주가 → 밸류에이션 순서로 설명.
PART 1 · 산업 이해

■ 메모리 칩은 어떻게 검사하나

단계하는 일장비 / 디아이 관련
① 웨이퍼 테스트웨이퍼 상태에서 칩 하나하나 전기가 통하는지 검사. 바늘(프로브카드)을 대고 테스터가 신호를 쏨웨이퍼 테스터 (디지털프론티어 DF-5100 = HBM4용)
② 패키징칩을 잘라서 포장. HBM은 여기서 칩 8~16장을 쌓음-
③ 번인 (Burn-In)포장된 칩을 125℃ 안팎 고온 + 높은 전압으로 몇 시간 돌려서 "곧 고장 날 칩"을 미리 걸러냄번인 테스터 + 번인 보드 (디아이 본사, 30년 넘게 국내 1위권)
④ 최종 테스트속도·기능 최종 확인 후 출하테스터(어드밴테스트 등) + 핸들러

- 번인 보드는 칩을 꽂는 판. 계속 쓰면 닳아서 교체해야 하는 소모품 → 장비 투자가 없어도 매출이 나옴 (국내 점유율 40%, 회사 추정)

- HBM이 검사를 늘림: HBM은 칩 여러 장을 쌓아서 하나가 불량이면 전체를 버림 → 쌓기 전에 웨이퍼 상태에서 꼼꼼히 걸러야 함(KGD). 그래서 HBM 웨이퍼 테스터 수요가 커짐

- DDR5·서버 D램도 번인이 길어짐: 서버용은 신뢰성 기준이 높아 번인 시간이 길고, 그만큼 장비가 더 필요

요약메모리는 웨이퍼 테스트 → 패키징 → 번인 → 최종 테스트. 디아이는 번인(본사)과 HBM 웨이퍼 테스트(자회사) 두 단계를 잡고 있음.

■ 이 산업은 언제 좋고 언제 나쁜가

- 검사장비는 메모리 회사가 새 공장·새 패키징 라인을 지을 때 대량으로 삼. 즉 메모리 투자 사이클을 그대로 탐

- 다만 전공정 장비보다 늦게 들어감 (공장 짓고 → 공정 장비 → 마지막에 검사장비). 그래서 메모리 투자 사이클 후반에 실적이 최대가 되는 경향

- 디아이 실적도 18년(DDR4 투자) 좋았다가 19년 적자, 25~26년 다시 최대. 24년엔 매출 2,140억에 영업이익 31억으로 거의 0
